# Discord bot bofh-api

Small bot that return sayings from the “Bastard operator from hell”
story via the BOFH REST API.

## API Reference

#### Get one quote from BOFH REST API

```discord
  /it-excuses
```

| Parameter  | Type     | Description                            |
| :--------- | :------- | :------------------------------------- |
| `language` | `string` | **Optional**. English,German or France |

#### Test command, answers with a "Pong!"

```discord
  /ping
```

#### Administration command to reload and update (/) commands

```discord
  /reload-commands
```
